OpenFocus AgentSpace Advanced Editor Design

Status

- Scope: design only, no implementation in this change.
- Target surface: AgentSpace, specifically the existing FILES / PREVIEW / TERMINAL workspace.
- Product fit: keep AgentSpace read-oriented and agent-native. This is not a full IDE replacement; it adds fast code navigation, search, and customizable IDEA-style shortcuts around the existing terminal-driven workflow.

Background

AgentSpace already has the right base shape:

- FILES is a read-only workspace tree.
- PREVIEW is a read-only CodeMirror preview for code, Markdown, and images.
- TERMINAL is the remote terminal area for external agents and shell workflows.
- Terminal output can already open workspace file references in PREVIEW.
- File operations already flow through Companion and are constrained to AgentSpace.root_path.

The advanced editor feature should extend that surface instead of creating a separate editor page. The goal is to let users quickly search, jump, and inspect code while an agent works in the terminal.

Goals

1. Support workspace search.
2. Support file/symbol search.
3. Support jump to definition.
4. Support finding function/variable usage and call locations.
5. Support IDEA-style keyboard shortcuts by default.
6. Add a custom shortcut tab in AgentSpace Settings so users can remap the main commands.
7. Preserve terminal/TUI behavior. AgentSpace must not steal important terminal shortcuts while focus is inside the terminal iframe.
8. Keep all file and code-navigation access inside the AgentSpace workspace root.

Non-goals

- Do not make PREVIEW a write editor in V1.
- Do not run arbitrary user commands for indexing/search.
- Do not expose Companion as a generic remote-control API.
- Do not require every language server to be installed before the feature is useful.
- Do not automatically mutate project files based on search/navigation actions.

User Experience

Primary entry points

- Search Everywhere overlay:
  - Default shortcut: Double Shift.
  - Also reachable from PREVIEW toolbar as a search icon button.
  - Searches files, symbols, and text snippets in one command palette.

- Find in Files overlay:
  - Default shortcut: Cmd+Shift+F on macOS, Ctrl+Shift+F elsewhere.
  - Shows query input, include/exclude filters, case toggle, regex toggle, and result grouping by file.

- Go to Definition:
  - Default shortcut: Cmd+B on macOS, Ctrl+B elsewhere.
  - Also supported by Cmd/Ctrl-click on a symbol in PREVIEW.
  - Opens the definition in PREVIEW and highlights the target line.

- Find Usages:
  - Default shortcut: Alt+F7.
  - Shows a right-side result drawer or overlay result panel.
  - Results are grouped by file, then by line.
  - Semantic LSP results are labeled "Usages"; fallback text matches are labeled "Text matches".

- Navigation history:
  - Default shortcuts:
    - macOS: Cmd+[ and Cmd+]
    - Windows/Linux: Ctrl+Alt+Left and Ctrl+Alt+Right
  - Tracks PREVIEW opens from file tree, terminal file references, definitions, usages, and search results.

AgentSpace Settings: Shortcuts Tab

The existing AgentSpace Settings modal is opened from the Start Agent edit button. It currently owns:

- Start Agent command.
- FILES / PREVIEW / TERMINAL font sizes.
- FILES / PREVIEW / TERMINAL visibility toggles.

V1 should convert the modal body into tabs:

- General
  - Start Agent command.
  - Pane visibility controls.

- Appearance
  - FILES font size.
  - PREVIEW font size.
  - TERMINAL font size.

- Shortcuts
  - A configurable list of command bindings.
  - Each row shows command name, current binding, default binding, scope, and actions.
  - Actions: Record, Reset, Clear.
  - Save persists the full settings set.

Shortcut commands exposed in V1

- search_everywhere

  - Default: Double Shift
  - Scope: global except active terminal input

- find_in_files
  - Label: Find in Files
  - Default: Meta+Shift+F on macOS, Ctrl+Shift+F elsewhere
  - Scope: global except active terminal input

- go_to_definition
  - Label: Go to Definition
  - Default: Meta+B on macOS, Ctrl+B elsewhere
  - Scope: PREVIEW

- find_usages
  - Label: Find Usages
  - Default: Alt+F7
  - Scope: PREVIEW

- navigation_back
  - Label: Navigate Back
  - Default: Meta+[ on macOS, Ctrl+Alt+ArrowLeft elsewhere
  - Scope: AgentSpace

- navigation_forward
  - Label: Navigate Forward
  - Default: Meta+] on macOS, Ctrl+Alt+ArrowRight elsewhere
  - Scope: AgentSpace

- focus_files
  - Label: Focus Files
  - Default: Alt+1
  - Scope: AgentSpace

- focus_preview
  - Label: Focus Preview
  - Default: Alt+2
  - Scope: AgentSpace

- focus_terminal
  - Label: Focus Terminal
  - Default: Alt+3
  - Scope: AgentSpace

Shortcut storage

- Store shortcuts in localStorage as client-side presentation state.
- Suggested key: openfocus.agent_space.shortcuts.v1.
- Keep this separate from durable AgentSpace domain records.
- This matches the existing AgentSpace UI settings boundary: pane visibility and font sizes are already browser-local presentation settings.

Example:

Shortcut recording rules

- The Shortcuts tab has a "Record" action per command.
- While recording, show "Press shortcut".
- Escape cancels recording.
- Backspace clears the binding.
- Enter confirms if a valid combination was captured.
- Double Shift is treated as a special sequence, not a normal key chord.
- A shortcut cannot conflict with another enabled AgentSpace shortcut.
- If a conflict is detected, show the conflicting command and require the user to clear or replace it.
- Plain text keys without modifiers are rejected except function keys and Double Shift.
- Do not allow remapping browser-reserved combinations known to be unreliable, such as Cmd+L, Cmd+R, Cmd+W, Cmd+T, Cmd+N.

Shortcut scope and terminal safety

- When focus is inside the terminal iframe, do not intercept ordinary key chords.
- Double Shift may be detected at the parent page level only if it does not send text/input to the terminal. If iframe focus prevents reliable detection, the terminal remains authoritative.
- PREVIEW shortcuts only run when PREVIEW has focus or a current preview selection/cursor.
- Global AgentSpace shortcuts run when focus is in FILES, PREVIEW, Settings, or overlays, but not when an editable input is actively typing unless the shortcut is explicitly supported there.

CodeMirror integration

- Keep PREVIEW read-only.
- Track current cursor/selection in CodeMirrorPreview.
- Expose current symbol context:
  - relPath
  - line
  - column
  - selectedText
  - wordAtCursor
- For Go to Definition and Find Usages, prefer selected text; otherwise use wordAtCursor.
- Use existing openPreview(relPath, name, target) to open target locations.
- Reuse the existing target line decoration and scroll-to-line behavior.

Backend Architecture

Add a new domain module:

- openfocus/domains/code_navigation/SPEC.md
- openfocus/domains/code_navigation/service.py

Responsibilities:

- Normalize search/query parameters.
- Validate AgentSpace exists.
- Resolve Companion and online status through the web adapter.
- Define stable result DTOs for files, symbols, text matches, definitions, and references.
- Keep domain logic independent from FastAPI request/response objects.

Add web routes:

- GET /api/agent_spaces/{space_id}/code/search
  - Query params:
    - q
    - kind: all | file | text | symbol
    - include
    - exclude
    - case_sensitive
    - regex
    - limit
  - Returns grouped results.

- GET /api/agent_spaces/{space_id}/code/symbols
  - Query params:
    - q
    - limit
  - Returns file-level or workspace-level symbols.

- POST /api/agent_spaces/{space_id}/code/definition
  - Body:
    - path
    - line
    - column
    - symbol
  - Returns zero or more definition locations.

- POST /api/agent_spaces/{space_id}/code/references
  - Body:
    - path
    - line
    - column
    - symbol
  - Returns zero or more reference locations.

- GET /api/agent_spaces/{space_id}/code/status
  - Returns available capabilities:
    - ripgrep_available
    - lsp_available
    - active_language_servers
    - fallback_mode

Companion Protocol

Add white-listed Companion commands rather than shelling out through terminal:

- CodeSearchRequest / CodeSearchResponse
- CodeSymbolsRequest / CodeSymbolsResponse
- CodeDefinitionRequest / CodeDefinitionResponse
- CodeReferencesRequest / CodeReferencesResponse
- CodeNavigationStatusRequest / CodeNavigationStatusResponse

All requests include:

- request_id
- root_path
- path when operating on a current file
- query/symbol/position fields as needed
- max_results
- timeout_ms

All responses include:

- ok
- error
- truncated
- backend: rg | lsp | text_fallback
- results

Search backend

- Prefer rg --json for text search.
- Use a fixed allowlisted argv shape. Do not pass raw user text through shell.
- Default excludes:
  - .git
  - node_modules
  - .venv
  - venv
  - dist
  - build
  - target
  - .next
  - coverage
  - __pycache__
- Limit:
  - default 100 results
  - max 500 results
  - timeout 3 seconds for V1
- Fallback:
  - Python filesystem walk with the same excludes.
  - UTF-8 decode with replacement.
  - skip binary-looking files.
  - skip files larger than a configured max, suggested 1 MB for text search.

Symbol backend

V1 can support two layers:

1. Fast fallback:
   - Parse visible/read files with simple language-aware regex for common declarations.
   - Python: def, class, async def, assignment names.
   - JS/TS: function, class, const/let/var, export function, methods.
   - Go/Rust/Java/PHP: basic function/class/type patterns.
   - Label results as "Approximate symbols".

2. LSP-backed:
   - If a supported language server is installed, start it lazily per root_path/language.
   - Use documentSymbol/workspaceSymbol where possible.
   - Label results as "Symbols".

Definition/references backend

- Prefer LSP textDocument/definition and textDocument/references.
- If LSP is unavailable or fails:
  - Definition fallback searches likely declaration patterns for the symbol.
  - References fallback uses word-boundary text search.
  - Result UI labels fallback results as "Text matches" or "Possible definitions".

Language server policy

- LSP is optional.
- Companion should detect installed servers with shutil.which.
- Suggested allowlist:
  - TypeScript/JavaScript: typescript-language-server
  - Python: pyright-langserver
  - Go: gopls
  - Rust: rust-analyzer
  - C/C++: clangd
  - Java: jdtls, later if needed
- Language servers are started only for active AgentSpace roots.
- Idle servers shut down after an inactivity timeout, suggested 10 minutes.
- LSP process stdout/stderr should not be shown in terminal.
- LSP process failures should degrade to fallback mode, not block AgentSpace.

Security

- All operations are rooted at AgentSpace.root_path.
- Reuse Companion path validation semantics: reject absolute rel_path input and path traversal; normalize and ensure resolved path remains under root.
- Do not return results outside root_path.
- Do not expose arbitrary process execution.
- Do not include code snippets in audit memory.
- Only record low-sensitive metadata for audit:
  - action kind
  - query length
  - result count
  - backend
  - elapsed time
  - truncated flag
- Enforce max query length, suggested 500 chars.
- Enforce max symbol length, suggested 200 chars.
- Enforce result and timeout limits.

Frontend Result Behavior

- Selecting any result opens PREVIEW at the result path/line/column.
- The result list remains open until dismissed, enabling quick scanning.
- Enter opens selected result.
- Cmd/Ctrl+Enter opens selected result and closes overlay.
- Escape closes overlay.
- Up/Down moves result selection.
- The search input supports debounced search, suggested 200 ms.
- Show "No results" only after a request completes.
- Show backend/fallback status subtly, not as debug text.

Failure Behavior

- Companion offline:
  - Show "Companion offline" in overlays.
  - Do not hide existing preview.

- rg missing:
  - Use fallback search.
  - status endpoint reports ripgrep_available=false.

- LSP missing:
  - Definition and usages use fallback.
  - UI labels results as fallback text/possible results.

- Timeout:
  - Return partial results with truncated=true when available.
  - UI shows "Partial results".

- Unsupported file type:
  - Search still works.
  - Symbol/definition/references may fallback or return no semantic result.

Manual E2E:

1. Create/open an AgentSpace.
2. Open a code file in PREVIEW.
3. Press Double Shift and search for a file.
4. Press Cmd/Ctrl+Shift+F and search text.
5. Put cursor on a symbol and press Cmd/Ctrl+B.
6. Press Alt+F7 and inspect usages.
7. Remap Find in Files in Settings -> Shortcuts.
8. Verify the old shortcut no longer fires and the new shortcut does.
9. Focus terminal and verify normal terminal shortcuts are not stolen.

Open Questions

- Whether Shortcut settings should live only inside AgentSpace Settings, or also be reachable from global System settings later.
- Whether LSP should be V1 or V1.5. The feature is useful with rg/text fallback first.
- Whether symbol indexing should be persisted per AgentSpace. Recommendation: no persistence in V1; keep it in-memory or on-demand.
- Whether PREVIEW should gain multi-tab file previews. Recommendation: not required for this feature; navigation history is enough for V1.
